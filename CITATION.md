# Citing KOVA3

## Citing the dataset

When you use KOVA3, cite the resource **and state the release version**.
Allele frequencies change between releases; an analysis is not reproducible
without the version.

```
Korean Variant Archive 3 (KOVA3), release vX.Y.Z.
Choi Laboratory, Korea University College of Medicine.
Registry of Open Data on AWS: TODO-registry-url
```

## Citing the predecessors

KOVA3 builds on two earlier Korean variant frequency resources. If your work
draws on the KOVA lineage rather than only the current release, cite these as
well.

- **KOVA** — Korean Variant Archive. *Scientific Reports*, 2017.
- **KOVA2** — Korean Variant Archive 2. *Experimental & Molecular Medicine*,
  2022. 5,305 individuals.
